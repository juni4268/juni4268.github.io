시간이 갈수록 몰려오는 몬스터

몬스터는 맵에 놓아 둔 생성 지점 중 한 곳에서 무작위로 나옵니다. 다음 몬스터가 나오기까지의 간격은 경과 시간에 따라 네 단계로 줄어들어, 후반으로 갈수록 몬스터가 몰려옵니다.

정예 몬스터는 시작할 때 한 마리, 그 뒤로 1분마다 한 마리씩 추가로 나옵니다. 정예 몬스터에게 맞으면 일반 몬스터의 두 배 피해를 받습니다.

영상은 시작 직후, 1분 무렵, 종료 직전을 차례로 보여줍니다.

경과 시간생성 간격
시작 ~ 1분2.5 ~ 3초
1분 ~ 2분2 ~ 3초
2분 ~ 2분 30초2 ~ 2.5초
2분 30초 ~ 3분1.5 ~ 2.5초

생성 간격

몬스터를 만들 때마다 경과 시간을 확인해 간격의 범위를 다시 정하고, 그 범위 안에서 무작위로 고른 시간 뒤에 다음 생성을 예약합니다.

생성 간격 코드 MonsterSpawnManager.cpp 
float time = UGameplayStatics::GetRealTimeSeconds(GetWorld());

if (time >= 150.f)
{
    minSpawnTime = 1.5f;
    maxSpawnTime = 2.5f;
}
else if (time >= 120.f)
{
    minSpawnTime = 2.0f;
    maxSpawnTime = 2.5f;
}
else if (time >= 60.f)
{
    minSpawnTime = 2.0f;
    maxSpawnTime = 3.0f;
}
else if (time >= 1.f)
{
    minSpawnTime = 2.5f;
    maxSpawnTime = 3.0f;
}
// ...
float spawnTime = FMath::RandRange(minSpawnTime, maxSpawnTime);
GetWorld()->GetTimerManager().SetTimer(
    timerHandle, this, &AMonsterSpawnManager::SpawnMonster, spawnTime);

정예 몬스터

경과 시간을 분 단위로 바꿔 마지막으로 정예 몬스터를 만든 분과 비교합니다. 분이 바뀌었으면 정예 몬스터를 한 마리 만듭니다.

정예 몬스터 코드 MonsterSpawnManager.cpp 
int currentMinute = time / 60;
if (currentMinute > lastSpawnMinute)
{
    int bossSpnCnt = FMath::RandRange(0, monsterSpawnPoints.Num() - 1);
    GetWorld()->SpawnActor<AMonster>(
        monsterCollection[1], monsterSpawnPoints[bossSpnCnt]->GetActorLocation(), FRotator(0), Params);
    lastSpawnMinute = currentMinute;
}

몬스터 AI

몬스터의 행동은 대기, 이동, 피격, 사망 네 가지 상태로 나눴습니다. 상태 처리는 몬스터에 붙이는 컴포넌트 하나에 모아서, 일반 몬스터와 정예 몬스터가 같은 코드를 씁니다.

이동 상태에서는 플레이어까지 가는 길이 있으면 플레이어를 쫓고, 길이 없으면 주변의 임의 지점으로 움직입니다. 공격 거리 안에 들어오면 멈춰서 플레이어 쪽으로 돌아보며 공격합니다.

상태 처리

매 프레임 현재 상태에 맞는 함수를 하나만 실행합니다. 대기 시간과 공격 간격은 같은 시간 변수로 잽니다.

상태 처리 코드 MonsterAI.cpp 
switch (aiState)
{
case MonsterState::IdleState:
    IdleState();
    break;
case MonsterState::MoveState:
    MoveState();
    break;
case MonsterState::DamageState:
    DamageState();
    break;
case MonsterState::DeathState:
    DeathState();
    break;
}
currentTime += GetWorld()->DeltaTimeSeconds;

이동과 공격

내비게이션으로 플레이어까지의 경로를 먼저 확인합니다. 경로가 없을 때는 미리 골라 둔 임의 지점으로 가고, 도착하면 새 지점을 고릅니다.

이동 코드 MonsterAI.cpp 
void UMonsterAI::MoveState()
{
    if (CreateNaviPath(monster->GetActorLocation(), player->GetActorLocation()))
    {
        aiControl->MoveToLocation(player->GetActorLocation());
    }
    else
    {
        auto result = aiControl->MoveToLocation(randLocation);
        if (result == EPathFollowingRequestResult::AlreadyAtGoal)
        {
            GetRandomLocation(monster->GetActorLocation(), 500, randLocation);
        }
    }
    FVector dir = player->GetActorLocation() - monster->GetActorLocation();
    if (dir.Size() < attackRange)
    {
        aiControl->StopMovement();
        anim->aiState = aiState;
        //aiState = MonsterState::IdleState;
        Attack();
    }
}

플레이어 스킬

플레이어는 기본 공격과 두 가지 스킬을 씁니다. 스킬마다 다시 쓸 수 있을 때까지 남은 시간을 화면에 표시합니다.

영상은 세 가지를 차례로 보여줍니다. 아래 표에서 스킬 이름을 누르면 그 스킬만 따로 재생됩니다.

스킬동작재사용 대기
마법 투사체 발사. 맞은 대상과 그 주변의 몬스터에게 함께 피해0.8초
바라보는 방향으로 순간이동20초
발밑에 마법진을 깔고 2초 뒤 폭발. 범위 안의 몬스터를 처치45초

기본 공격의 범위 피해

투사체가 맞은 지점을 중심으로 주변의 몬스터를 찾아 피해를 줍니다. 직접 맞은 대상은 이미 피해를 받았으므로 검사에서 제외합니다.

범위 피해 코드 Arrow.cpp 
void AArrow::ApplyAreaDamage(const FVector& Center, AActor* IgnoredActor)
{
    const float SphereRadius = 200.f;
    TArray<FOverlapResult> Overlaps;
    FCollisionShape Sphere = FCollisionShape::MakeSphere(SphereRadius);

    FCollisionQueryParams Params;
    Params.AddIgnoredActor(this);
    if (IgnoredActor)
    {
        Params.AddIgnoredActor(IgnoredActor); // 직접 충돌한 대상은 다시 제외
    }
    // ...
    bool bHit = GetWorld()->OverlapMultiByChannel(
        Overlaps,
        Center,
        FQuat::Identity,
        ECollisionChannel::ECC_Pawn, // 또는 몬스터가 사용하는 채널
        Sphere,
        Params
    );
    // ...
}

순간이동

맵의 땅이 평지가 아니라서 도착 지점이 땅속이 되는 경우가 있었습니다. 순간이동에 실패하면 도착 지점을 위로 올려 한 번 더 시도하게 했습니다.

FVector Destination = StartLocation + Forward * 800.f;

bool bTeleported = TeleportTo(Destination, GetActorRotation());

if (!bTeleported)
{
    // 실패 시 살짝 위로 이동해서 재시도

범위 스킬의 지연 폭발

스킬을 쓴 위치를 기억해 두었다가 2초 뒤에 그 자리에서 폭발시킵니다. 그사이 플레이어가 움직여도 폭발 위치는 바뀌지 않습니다.

지연 폭발 코드 Arusa.cpp 
// 2단계: 2초 후 폭발 이펙트 + 데미지
GetWorld()->GetTimerManager().SetTimer(SkillExplosionDelayHandle, FTimerDelegate::CreateLambda([this, SkillLocation]()
    {
        // ...
        // 스킬 범위 안의 몬스터 탐색
        TArray<FHitResult> HitResults;
        bool bHit = GetWorld()->SweepMultiByChannel(
            HitResults,
            SkillLocation,
            SkillLocation,
            FQuat::Identity,
            ECC_Pawn,
            FCollisionShape::MakeSphere(ExplosionRadius)
        );

        for (auto& Hit : HitResults)
        {
            AActor* HitActor = Hit.GetActor();
            if (!HitActor || HitActor == this) continue;

            // 몬스터인지 확인하고 데미지 함수 호출
            if (auto monster = Cast<AMonster>(HitActor))
            {
                auto ai = HitActor->GetDefaultSubobjectByName(TEXT("AI"));
                if (ai)
                {
                    Cast<UMonsterAI>(ai)->OnMonsterDamage(ExplosionDamage);
                }
                // ...
            }
        }
    }), 2.f, false);
