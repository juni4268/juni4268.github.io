비헤이비어 트리로 만든 보스 AI

보스의 행동은 비헤이비어 트리로 구성했습니다. 근접 공격, 돌진, 점프 공격, 원거리 공격을 각각 하나의 노드로 나누고, 트리가 상황에 맞는 공격을 고릅니다.

판단에 필요한 값은 서비스 노드가 0.1초마다 모아 줍니다. 플레이어와의 거리, 현재 페이즈, 기절 여부, 공격 중인지, 패턴마다 남은 대기 시간이 여기서 갱신됩니다.

상태 갱신

서비스 노드는 보스와 애니메이션 상태를 읽어 블랙보드에 적습니다. 트리의 조건 노드들은 이 값만 보고 다음 행동을 정합니다.

상태 갱신 코드 BTService_UpdateBossState.cpp 
BlackboardComp->SetValueAsBool(IsAttackKey.SelectedKeyName, BossAnim->isAttack);
BlackboardComp->SetValueAsBool(IsStunnedKey.SelectedKeyName, Boss->bIsStunned);
BlackboardComp->SetValueAsInt(BossPhaseKey.SelectedKeyName, Boss->currentPhase);
// ...
if (IsValid(TargetActor))
{

    BlackboardComp->SetValueAsFloat(PlayerDistanceKey.SelectedKeyName, Distance);

보스가 멈추는 문제

공격 중이라는 표시가 켜진 채로 남아 보스가 다음 행동을 하지 못하는 경우가 있었습니다. 표시는 켜져 있는데 재생 중인 공격 애니메이션이 없으면 표시를 끄도록 했습니다. 점프 공격은 공중에 있는 동안 애니메이션이 없을 수 있어서 이 검사에서 제외했습니다.

멈춤 방지 코드 BTService_UpdateBossState.cpp 
// --- Watchdog: Force Reset isAttack if no montage is playing ---
// Skip this check if we are in a Jump Sequence (as there might be no montage playing mid-air)
if (BossAnim->isAttack && !BossAnim->Montage_IsPlaying(nullptr) && !Boss->IsInJumpSequence())
{
    UE_LOG(LogTemp, Warning, TEXT("Service Watchdog: isAttack is TRUE but no Montage playing. Resetting to FALSE."));
    BossAnim->isAttack = false;
}

보스 패턴과 세 페이즈

보스는 네 가지 공격을 씁니다. 체력이 3분의 2, 3분의 1 아래로 내려갈 때마다 페이즈가 바뀌어 세 단계로 진행되고, 페이즈가 바뀌면 보스의 겉모습에 덧씌우는 재질이 달라집니다.

영상은 네 가지 공격을 차례로 보여줍니다. 아래 표에서 공격 이름을 누르면 그 공격만 따로 재생됩니다.

패턴동작
양손에 붙인 판정 상자로 타격
준비 동작 뒤 바라보는 방향으로 직진. 기둥에 부딪히면 기절
보스가 사라지고 바닥 표시가 플레이어를 따라가다 멈추면 그 자리에 착지
번개를 부채꼴로 발사. 2페이즈부터 퍼지는 각도가 넓어짐

페이즈 전환

피해를 받을 때마다 남은 체력을 확인해 페이즈를 올립니다. 페이즈 값은 서비스 노드를 거쳐 트리로 전달됩니다.

페이즈 전환 코드 BossMonster.cpp 
// Phase transition logic

{

    bPhaseChanged = true;
    // ...
}
if (currentPhase == 2 && currentHP <= (maxHP * 1.0f / 3.0f))
{
    currentPhase = 3;
    bPhaseChanged = true;
    // ...
}

if (bPhaseChanged)
{
    UpdateOverlayMaterial();
}

점프 공격의 순서

보스를 숨기고 바닥 표시를 만든 뒤, 정해진 시간 동안 표시가 플레이어를 따라갑니다. 시간이 지나면 표시를 멈추고, 잠시 뒤 그 위치로 착지합니다. 단계 사이의 간격은 타이머로 잇습니다.

점프 공격 코드 BossMonster.cpp 
void ABossMonster::Jump_StartInAirPhase()
{
    // Hide actor
    SetActorHiddenInGame(true);

    // Spawn indicator actor
    if (JumpIndicatorClass)
    {
        // ...
        CurrentIndicator = GetWorld()->SpawnActor<AJumpAttackIndicator>(JumpIndicatorClass, SpawnLocation, GetActorRotation(), SpawnParams);
    }

    // Start timer to stop following the player
    GetWorldTimerManager().SetTimer(JumpFollowTimer, this, &ABossMonster::Jump_LockPositionAndPrepareLand, JumpFollowTime, false);
}

void ABossMonster::Jump_LockPositionAndPrepareLand()
{
    if (CurrentIndicator)
    {
        CurrentIndicator->StopFollowing();
    }
    // Start timer to actually land
    GetWorldTimerManager().SetTimer(JumpLandTimer, this, &ABossMonster::Jump_Land, JumpLandDelay, false);
}

돌진과 기둥

돌진은 준비와 돌진 두 단계로 나뉩니다. 준비 동작이 끝나는 순간의 방향으로 직진하고, 플레이어는 통과하지만 벽과 장애물에는 부딪힙니다.

돌진하는 보스를 기둥으로 유도해 부딪히게 하면 보스가 기절해 공격할 틈이 생깁니다. 기둥은 정해진 횟수만큼 부딪히면 쓰러지고, 쓰러진 기둥은 더 이상 보스를 기절시키지 않습니다.

돌진 중 충돌

돌진 중에 부딪힌 대상이 기절을 일으키는 벽이면 기둥에 충격을 전달하고 보스를 기절시킵니다. 그 밖의 장애물이면 돌진만 멈춥니다.

돌진 충돌 코드 BossMonster.cpp 
// Check if the actor we hit is a stunnable wall
if (OtherActor->ActorHasTag(TEXT("StunnableWall")))
{
    AStunnablePillar* Pillar = Cast<AStunnablePillar>(OtherActor);
    if (Pillar)
    {
        Pillar->TakeHitFromBoss(GetActorForwardVector());
    }
    // Stun regardless of whether it was a pillar class, as long as it has the tag
    Stun();
}

쓰러지는 기둥

기둥은 부딪힌 횟수를 세다가 한도에 닿으면 물리 시뮬레이션을 켜고, 보스가 달려온 방향으로 밀려 쓰러집니다. 이때 기절을 일으키는 표시를 떼어 냅니다.

기둥 코드 StunnablePillar.cpp 
void AStunnablePillar::TakeHitFromBoss(FVector BossForwardVector)
{
    if (bIsBroken) return;

    CurrentHits++;
    // ...
    if (CurrentHits >= MaxHits)
    {
        // ...
        bIsBroken = true;

        // Enable Physics to make it fall
        MeshComp->SetSimulatePhysics(true);
        MeshComp->SetCollisionProfileName(TEXT("PhysicsActor")); // Change to physics-enabled profile

        // Apply a push in the direction the boss was dashing
        // Increased strength significantly
        FVector Impulse = BossForwardVector * (FallImpulseStrength * 5.0f);
        // Apply slightly upwards so it tips over nicely
        Impulse.Z += (FallImpulseStrength * 2.0f);

        MeshComp->AddImpulse(Impulse);

        // Optional: Remove the tag so the boss doesn't get stunned by the debris on the floor
        Tags.Remove(TEXT("StunnableWall"));
        // ...
    }
}

강해지는 보스와 랩타임

보스를 쓰러뜨리면 레벨이 올라 다시 등장합니다. 레벨이 오를 때마다 체력, 공격별 피해량, 번개의 속도가 함께 올라갑니다. 레벨 3의 보스를 쓰러뜨리면 클리어입니다.

보스 하나를 쓰러뜨리는 데 걸린 시간을 랩타임으로 기록하고, 레벨 순서대로 보여 줍니다.

레벨에 따른 수치

보스가 등장할 때 레벨에 맞춰 수치를 다시 계산합니다.

보스 레벨 코드 BossMonster.cpp 
void ABossMonster::LevelUpBoss()
{
    // Scale HP: InitialHP + 500 per level
    maxHP = InitialHP + (BossLevel * 150.0f);
    currentHP = maxHP;

    // Scale Damage based on BossLevel using base values defined in header as reference
    // Base Punch: 5, Dash: 20, Jump: 20, Lightning: 10
    PunchDamage = BossLevel * 5.0f;
    DashDamage = 10.0f + (BossLevel * 5.0f);
    JumpDamage = 10.0f + (BossLevel * 5.0f);
    BossLightningDamage = BossLevel * 5.0f;
    BossLightningSpeed = 850.0f + (BossLevel * 50.0f);
    // ...
}

랩타임 기록

기록은 레벨이 바뀌어도 남도록 게임 인스턴스에 보관하고, 추가할 때마다 보스 레벨 순으로 정렬합니다.

랩타임 코드 AKAGameInstance.cpp 
void UAKAGameInstance::AddLapTime(int32 Level, float Time)
{
    FLapTimeData NewRecord;
    NewRecord.BossLevel = Level;
    NewRecord.LapTime = Time;
    LapTimeRecords.Add(NewRecord);

    // Sort by BossLevel (Ascending) to show progression
    LapTimeRecords.Sort([](const FLapTimeData& A, const FLapTimeData& B)
    {
        return A.BossLevel < B.BossLevel;
    });
}
