사고 이벤트의 공통 구조

공장에서 일어나는 사고 여덟 가지를 이벤트로 만들었습니다. 이벤트마다 코드를 따로 만들지 않고, 공통 기능을 부모 클래스 하나에 모은 뒤 각 이벤트는 조건과 결과만 다르게 구현했습니다.

이벤트는 대기, 발생, 조작 중, 해결, 실패 다섯 상태를 가집니다. 상태가 바뀌면 위치 표시 마커와 상호작용, 화면 표시가 함께 바뀝니다.

아래 표에서 사고 이름을 누르면 그 사고를 해결하는 영상이 재생됩니다.

사고실패 조건해결
밟으면 낙상제습지로 제거
압력 180 도달 시 폭발밸브 조작
연기 농도가 한계를 넘으면 질식공조기 필터
안전모 미착용 시 압사안전모 착용
제한 시간 안에 끄지 못하거나 불에 닿으면 사망CO2 소화기

절연 장갑 없이 만지면 감전절연 장갑을 끼고 레버 조작

모든 이벤트가 같은 상태 값을 씁니다. 상태를 바꾸는 함수는 하나이고, 여기서 마커와 화면에 변경을 알립니다.

상호작용 조건

플레이어가 이벤트를 조작하면 부모 클래스가 먼저 조건을 확인합니다. 사고가 나지 않은 설비이면 정상 가동 중이라고 알리고, 필요한 아이템이 없거나 다른 아이템을 들고 있으면 안내 문구를 띄웁니다. 조건을 통과한 뒤의 동작만 각 이벤트가 따로 구현합니다.

상호작용 검사 코드 CPREventBase.cpp

{
    // ...
    if (CurrentStatus == ECPREventStatus::Idle)

        {
            TargetCharacter->ShowErrorMessage(FText::FromString(TEXT("잘못된 아이템입니다!")));
            return;
        }
    }

    ReceiveInteractionValidated(TargetCharacter);
}

제한 시간

이벤트가 발생 상태가 되면 부모 클래스가 제한 시간 타이머를 겁니다. 시간이 다 되면 실패 상태로 바꾸고 사망 연출을 실행합니다. 화면에서는 폭발, 화재처럼 사고마다 다르게 보이지만, 시간이 다 됐을 때의 처리는 이 함수에서 시작합니다. 화재, 기계 과열, 보일러는 이 함수를 이어받아 각자의 사망 연출만 바꿉니다.

void ACPREventBase::OnTimerExpired()
{
    if (CurrentStatus == ECPREventStatus::Resolved || CurrentStatus == ECPREventStatus::Failed)
    {
        return;
    }

    ReceiveEventTimeOut();
    SetEventStatus(ECPREventStatus::Failed);
    HandleDieSequence();
}

소화기와 화재

소화기는 일반, CO2, D급 세 종류이고, 화재는 종류에 맞는 소화기로만 끌 수 있습니다. 전기 화재는 CO2 소화기, 금속 화재는 D급 소화기를 써야 하고, 다른 소화기를 뿌리면 불이 줄지 않습니다.

소화기는 불이 어떤 이벤트인지 알지 못합니다. 맞은 대상이 소화할 수 있는 대상인지만 확인하고, 불이 줄어드는 처리는 각 화재가 맡습니다. 전기 화재, 금속 화재, 기계 과열로 난 불이 같은 방식으로 꺼집니다.

소화 가능한 대상

소화할 수 있는 대상은 인터페이스 하나를 구현합니다. 함수는 소화량과 소화기 종류를 받습니다.

소화 인터페이스 코드 CPRExtinguishable.h

화재 쪽의 판정

화재는 자기에게 맞는 소화기인지 확인한 뒤 불 세기를 줄입니다. 불 세기가 0이 되면 이벤트를 해결 상태로 바꿉니다.

기계 과열

기계는 오일과 냉각수를 계속 소모합니다. 둘 중 하나가 바닥나면 온도가 오르고, 둘 다 바닥나면 더 빨리 오릅니다. 250°C에 닿으면 불이 납니다.

플레이어는 기계 앞에서 오일과 냉각수를 채워 온도를 내립니다. 두 게이지가 모두 일정 비율 이상일 때만 온도가 내려갑니다. 불이 난 뒤에는 일반 소화기로 꺼야 합니다.

온도 계산

매 프레임 오일과 냉각수의 남은 양으로 온도 변화를 정합니다. 온도가 최대치에 닿으면 과열을 일으키고, 그 뒤로는 화재 이벤트와 같은 방식으로 소화기로 끕니다.

온도 계산 코드 CPREvent_Overheat.cpp 
const bool bOilEmpty     = (OilCurrent <= 0.f);
const bool bCoolantEmpty = (CoolantCurrent <= 0.f);

if (bOilEmpty || bCoolantEmpty)
{
    const float RiseRate = (bOilEmpty && bCoolantEmpty) ? TempRiseBothEmpty : TempRiseRateOneEmpty;
    TempCurrent += RiseRate * DeltaTime;
}
else
{
    const float OilRatio     = (OilMax > 0.f)     ? (OilCurrent / OilMax)         : 0.f;
    const float CoolantRatio = (CoolantMax > 0.f) ? (CoolantCurrent / CoolantMax)  : 0.f;
    if (OilRatio >= TempDecreaseThresholdRatio && CoolantRatio >= TempDecreaseThresholdRatio)
    {
        TempCurrent -= TempDecreaseRate * DeltaTime;
    }
}

TempCurrent = FMath::Clamp(TempCurrent, TempMin, TempMax);
// ...
if (TempCurrent >= TempMax)
{
    TriggerOverheat();
    return;
}

루프와 퇴근 조건

사고를 막지 못해 쓰러지면 결과 화면이 나온 뒤 같은 날 출근부터 다시 시작합니다. 안전 점검 목록의 항목을 모두 끝내야 퇴근할 수 있고, 그 전에는 출구에 가도 끝나지 않습니다.

목록이 모두 끝나면 출구 표시가 바뀌고, 플레이어가 출구에 들어섰을 때 남은 과열 진행과 소리를 멈춘 뒤 엔딩으로 넘어갑니다.

퇴근 조건

출구는 안전 점검 목록이 모두 끝났다는 신호를 받아야 열립니다. 조건이 충족된 상태에서 플레이어가 들어오면 한 번만 클리어를 처리합니다.

퇴근 처리 코드 CPRClearTrigger.cpp 
if (bConditionsMet)
