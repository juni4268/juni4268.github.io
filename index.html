게임 프로그래밍 전체를 맡은 작품도 있고, 다른 프로그래머와 역할을 나눠 개발한 작품도 있습니다.

작품

  • SteamHeart →

    Unity 6 · C#

    할아버지의 기계 심장을 되살릴 코어를 찾아 도시의 하층에서 상층으로 올라가는 2D 액션 어드벤처.

    담당 게임 프로그래밍 전체 · UI 제작(AI 활용)

  • 수호의 창

    Unreal Engine 5.6 · C++ · PaperZD

    몬스터와 싸워 경험치를 쌓고, 레벨이 오르면 강화할 능력을 선택하는 2D 픽셀 액션 게임.

    담당 게임 프로그래밍 · 프로그래머 2인 협업

  • AKA

    Unreal Engine 5.6 · C++

    던전에서 보스의 돌진과 번개 공격을 피하며 싸우는 탑뷰 보스 러시 액션 게임.

    담당 게임 프로그래밍

  • SAFE OUT

    Unreal Engine 5.7 · C++

    공장 설비의 과열과 사고에 대응하고, 모든 미션을 해결한 뒤 출구로 향하는 3D 탈출 게임.

    담당 게임 프로그래밍 전체

  • DAEVA

    Unreal Engine 5.4 · C++

    떠돌이 마법사가 되어 점점 늘어나는 몬스터를 상대로 3분간 버티는 3인칭 생존 게임.

    담당 게임 프로그래밍
