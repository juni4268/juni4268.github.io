작업 방식

코드 작성과 수정은 대부분 AI(GPT, Claude)에게 맡깁니다. 저는 기능이 어떤 조건에서 시작되고 끝나는지를 먼저 정해 지시하고, 결과를 직접 플레이하고 테스트해 확인합니다. 문제를 발견하면 재현 조건을 찾아, 무엇을 고쳐야 하는지 구체적으로 지시합니다.

사례: SteamHeart의 보스 패턴 선택

  1. 발견

    5분 시연을 준비하면서 직접 플레이하며 구간별 시간을 기록했습니다. 그 과정에서 보스의 내려찍기가 반복해서 선택되어 다른 공격이 나오지 않는 상황을 발견했습니다.

  2. 조건 정의

    아직 나오지 않은 공격을 먼저 고르고, 가장 위협적인 패턴은 첫 순환의 마지막에 나온다는 조건을 정했습니다.

  3. AI에 전달

    이 조건을 AI에 전달해 패턴 선택 코드를 수정했습니다.

  4. 확인

    수정 후 패턴 선택 관련 테스트 8개가 통과했습니다.
