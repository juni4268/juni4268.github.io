참여 작품

  • 2D 사이드뷰 액션 어드벤처

    SteamHeart

    스팀펑크 도시의 하층에서 출발해, 할아버지의 기계 심장을 되살릴 코어를 찾아 올라가는 픽셀 아트 액션 게임.

    개발 환경
    Unity 6, C#
    담당
    게임 프로그래밍, UI 제작

    대표 구현 사례

    • 보스의 동시 공격과 중단 처리 최종 보스의 손과 링 공격이 겹치도록 패턴마다 필요한 부위를 예약하고, 공격이 끝나거나 중단되면 같은 종료 처리로 정리합니다.
    • 사망 후에도 이어지는 성장 도전 중 상태와 영구 진행도를 분리해, 사망해도 고철과 강화 단계가 다음 도전에 남습니다.

  • 3D 공장 탈출 게임

    SAFE OUT

    공장 곳곳의 설비 이상과 사고에 대응하고, 모든 미션을 끝낸 뒤 출구로 탈출하는 게임.

    개발 환경
    Unreal Engine 5.7, C++
    담당
    게임 프로그래밍

    대표 구현 사례

    • 자원 관리에서 화재로 이어지는 과열 이벤트 오일·냉각수 잔량을 설비 온도와 연결하고, 온도가 한계에 이르면 화재로 전환해 피해 구역을 활성화합니다.
    • 사고 대응을 탈출 조건으로 연결한 미션 시스템 사건의 상태를 미션 UI에 표시하고, 모든 미션이 끝나면 출구 안내를 띄웁니다.

AI와 일하는 방식

이 포트폴리오에 있는 게임의 코드는 거의 전부 AI가 썼습니다. 제가 한 일은 무엇을 만들지 정해 지시하고, 결과를 직접 확인하고, 어긋난 부분을 조정하는 것입니다.

AI가 하는 일

지시한 기능의 코드 작성과 수정

내가 하는 일

만들 기능과 규칙 결정, 지시, 플레이와 테스트를 통한 확인, 조정

  1. 만들 것을 정한다

    기능이 게임에서 어떻게 동작해야 하는지 먼저 정합니다. 예를 들어 SteamHeart에서는 사망했을 때 체력과 무기 단계는 초기화하고 고철과 강화는 남긴다는 규칙을 정했습니다.

  2. AI에게 지시한다

    정한 동작을 설명하고 코드를 받습니다.

  3. 직접 확인한다

    게임을 플레이해 의도대로 움직이는지 보고, 테스트로도 확인합니다. SteamHeart의 보스 패턴에는 회귀 테스트를 붙였습니다.

  4. 조정한다

    의도와 다른 부분을 짚어 다시 지시하고, 맞을 때까지 반복합니다.
